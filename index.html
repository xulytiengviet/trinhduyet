Tôi có cần ESP32 hoặc Gmail không?

Chế độ chatbot trên trình duyệt không cần phần cứng ESP32 hay đăng nhập Google vào Trình Duyệt. Tài khoản XiaoZhi có thể cần cho việc kích hoạt. Chỉ khi quản lý ESP32 thật mới cần đăng nhập Google và nạp firmware.

Không nhận được mã kích hoạt?

Kiểm tra gateway trong BilaBot. Mã XiaoZhi do máy chủ cấp thật, không phải mã ghép nối ESP32 Cloud của Render. Nếu gateway chưa được cấu hình, không thể cấp mã.

FIRMWARE / 004

Cập nhật qua mạng.

Thiết bị yêu cầu manifest OTA từ Render API; nếu có firmware tương thích, ESP-IDF tải qua HTTPS và kiểm tra trước khi kích hoạt.

01
Đăng ký và nạp khóa

Cấu hình Device ID, khóa riêng và API URL qua kênh cấp phát an toàn vào ESP32.

02
Yêu cầu mã kích hoạt

Thiết bị gọi /api/device/pair/request và hiển thị 6 số; chủ sở hữu nhập mã trên web.

03
Gửi heartbeat và kiểm tra OTA

Chỉ thiết bị đã kích hoạt mới nhận manifest. Kiểm tra board, version, SHA-256 và HTTPS.

04
Xác thực firmware và khởi động lại

Ưu tiên firmware được ký bằng Secure Boot và hỗ trợ rollback khi khởi động thất bại.

Trạng thái phát hành

Bản phát hành firmware do quản trị viên cấu hình trên Render: FIRMWARE_VERSION, FIRMWARE_BOARD, FIRMWARE_URL và FIRMWARE_SHA256. Không có firmware được đặt sẵn, vì cần xác định đúng phần cứng và khóa ký.

QUẢN TRỊ · NÂNG CAO

Triển khai hệ thống.

Cloudflare Pages

Kết nối GitHub repository, Root directory esp32-cloud/frontend, Build command npm run build, Output directory dist. Khai báo biến PUBLIC_API_URL và PUBLIC_GOOGLE_CLIENT_ID trong phần build environment.

Render + PostgreSQL

Triển khai backend theo file render.yaml. Cấu hình GOOGLE_CLIENT_ID, ALLOWED_ORIGINS bằng URL Cloudflare Pages chính xác; cung cấp DATABASE_URL từ Render Postgres. Chỉ công bố địa chỉ API, không công bố khóa bí mật.

Google Cloud OAuth

Tạo OAuth Client ID loại Web application, bổ sung origin Cloudflare Pages vào Authorized JavaScript origins, sau đó dùng cùng Client ID cho frontend và Render. Không yêu cầu scope Gmail.

XiaoZhi & Go backend hiện có

Mã nguồn Go gốc của repository vẫn hoạt động độc lập. Backend Node quản lý thiết bị và xác thực Google; cấu hình giao thức XiaoZhi nằm trong stack Go hoặc gateway BilaBot. Việc phân tách tránh phá vỡ tuyến âm thanh hiện tại.
